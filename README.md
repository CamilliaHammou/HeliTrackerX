# HeliTrackerX

A web app for visualizing helicopter positions in real-time. This project simulates helicopter movements using random coordinates and displays them on a map with the Leaflet API.

## Files
- `index.html`: Main HTML file
- `style.css`: Styles for the application
- `script.js`: JavaScript for map initialization and helicopter simulation

## Setup
1. Clone the repository.
2. Open `index.html` in a web browser to view the application.

## Technologies
- HTML
- CSS
- JavaScript
- Leaflet API
